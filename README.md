# TradePilot AI Trading Dashboard

TradePilot AI is a static HTML/CSS/JavaScript prototype for an AI-assisted trading workspace. It includes simulated AI signals, a live-style chart, quick trade ticket, watchlist, alerts, strategy snapshot, and risk controls.

## Open locally

### Direct browser method

1. Download or clone this project.
2. Open the project folder.
3. Double-click `index.html`.

### Local server method

Run this command from the project root:

```bash
python3 -m http.server 4173
```

Then open this link in your browser:

```text
http://localhost:4173/
```

If your system uses `python` instead of `python3`, run:

```bash
python -m http.server 4173
```

## Public GitHub Pages link

This repo includes a GitHub Pages workflow. After this branch is pushed or merged and GitHub Pages is enabled with **GitHub Actions** as the source, the app will be available at:

```text
https://<your-github-username>.github.io/Learning-Fullstack-Development-/
```

Replace `<your-github-username>` with your actual GitHub username or organization name.
